Keep the alerts one tap away: install 5-Mins as an app on your phone, tablet or computer.

Install this app on your device

5-Mins works in any modern browser and can be installed as an app on Android, iPhone, iPad, Windows, macOS and Linux. Once installed it opens in its own window and still starts when you are offline.

  • Android — use Install app above or the browser menu → Add to Home screen.
  • iPhone and iPad — in Safari, tap Share → Add to Home Screen.
  • Windows and Linux — in Chrome or Edge, use Install app above or the install icon in the address bar.
  • macOS — in Safari, choose File → Add to Dock; in Chrome or Edge, use Install app above.

5-Mins is installed

You are already running 5-Mins as an app. Head to the world map or the setup page.

5-Mins is an informational tool. Always follow instructions from your local emergency services.
